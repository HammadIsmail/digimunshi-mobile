# DigiMunshi Mobile 📱🎙️

> **Voice-First Mobile Ledger Application for Pakistani Micro-Merchants & Shopkeepers**

DigiMunshi Mobile is an intuitive, voice-controlled digital khata (ledger) mobile app built with React Native and Expo. Designed specifically for Pakistani kiryana store and retail shop owners, it features an authentic, native Urdu script interface (نستعلیق / اردو) paired with conversational voice recording and playback.

- 🖥️ **Backend API Repository**: [digimunshi-backend](https://github.com/HammadIsmail/digimunshi-backend)
---

## 🌟 Key Features

- **Tap-and-Talk Voice Interaction**: Seamless voice recording via `expo-av` supporting tap-to-record or hold-to-speak workflows.
- **Authentic Urdu Script UI**: Beautiful, accessible typography rendered in pure Urdu (`کھاتہ بک`, `کل بقایا ادھار`, `بولنے کے لیے دبائیں`, `تصدیق فرمائیں`).
- **Interactive Audio Feedback**: In-memory Base64 audio playback of spoken Urdu confirmations generated by Uplift AI Orator.
- **Event-Driven Real-Time Sync**: Instant screen updates (`ledgerVersion` state sync) across dashboard, customer lists, and detail views without needing manual page reloads.
- **Visual Transaction Confirmation**: Color-coded badges indicating user speech (`🗣️ آپ نے کہا`) and DigiMunshi's response (`🤖 ڈیجی منشی`).
- **Confirmation Prompts**: Native confirmation cards for new customer additions, balance alterations, and khata clearance.
- **Itemized Khata & Payment Tracking**: Customer detail view displaying item descriptions (`بیڈ`, `چینی`, `راشن`) alongside itemized credit (`💳 ادھار`) and payment (`💰 وصولی`) records.

## 🛠️ Tech Stack

- **Framework**: [React Native](https://reactnative.dev/) with [Expo](https://expo.dev/) (SDK 52)
- **Routing**: [Expo Router](https://docs.expo.dev/router/introduction/) (File-based navigation)
- **Audio & Media**: [expo-av](https://docs.expo.dev/versions/latest/sdk/av/) for high-fidelity recording and stateless Base64 playback
- **State Management**: Zustand with event-driven `ledgerVersion` reactivity
- **Secure Storage**: [expo-secure-store](https://docs.expo.dev/versions/latest/sdk/securestore/) for encrypted JWT persistence
- **Language**: TypeScript

## 🚀 Getting Started

### 1. Prerequisites
- Node.js 18+ and npm / yarn
- [Expo Go](https://expo.dev/go) app installed on your physical Android or iOS device (or an Android/iOS emulator)

### 2. Installation

```bash
# Clone repository
git clone https://github.com/HammadIsmail/digimunshi-mobile.git
cd digimunshi-mobile

# Install dependencies
npm install
```

### 3. Environment Configuration

Create a `.env` file from `.env.example`:

```bash
cp .env.example .env
```

Set your backend API URL (use your local Wi-Fi IP when testing on a physical phone via Expo Go):

```env
EXPO_PUBLIC_API_URL=http://192.168.1.XX:8000
```

### 4. Start Development Server

```bash
npx expo start
```

Scan the QR code displayed in the terminal using the Expo Go app on your phone.
